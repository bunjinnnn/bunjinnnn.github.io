Privacy policy

Dendrite is a personal tool used only by its developer. This page explains how it handles Google user data.

What it reads

With permission given through Google sign-in, Dendrite reads the signed-in user's Google Classroom courses, coursework, course materials and announcements. It only reads this data and does not change anything in Google Classroom.

Where the data goes

The data is stored on the user's own computer so it can be shown inside Dendrite. It is not sent to any server run by Dendrite, not sold, not shared with anyone else, and not used for advertising.

Removing access

Access can be removed at any time at myaccount.google.com/permissions. Deleting Dendrite's data folder removes everything it saved.

Google API Services User Data Policy

Dendrite's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.
